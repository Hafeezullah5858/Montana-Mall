# Muntaha Mall

Full-stack Pakistani marketplace with customer accounts, seller center, admin product management, COD checkout and optional Safepay online payments.

## Features
- Customer registration/login/logout
- Server-side product catalogue and inventory
- Admin add/edit/delete products
- Seller application and product publishing
- Wishlist
- COD orders
- Safepay hosted online payments (sandbox/live via environment variables)
- Payment webhook verification and payment status tracking
- Admin order status management
- Automatic stock restoration for cancelled/expired unpaid online orders
- Secure password hashing and HttpOnly sessions
- Muntaha Mall logo included in `assets/`
