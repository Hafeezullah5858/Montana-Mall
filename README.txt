Muntaha Mall — Full Stack Marketplace

This package includes:
- Customer registration/login
- Seller center and seller product publishing
- Admin dashboard with Add/Edit/Delete products
- Product price, stock, category, description and image URL management
- COD checkout
- Safepay hosted online payment integration (sandbox/live via environment variables)
- Payment status + webhook verification
- Inventory and order management
- Muntaha Mall logo in assets/

Start locally with:
  npm start

For online payments, configure Safepay keys in the hosting provider's Environment Variables. Never commit payment secrets to GitHub.
